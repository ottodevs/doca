The narrative in three sentences

Aqua solved custody: you promise liquidity, you never deposit it. But promises can exceed your wallet by design, and the whitepaper's own fix is a human docking positions by hand. Plimsoll turns that chore into a product: budgets keep every promise honest, a Harbormaster keeps them honest while you sleep.

"While Aqua doesn't automatically pause illiquid positions, Makers are strongly recommended to manually dock strategies that become chronically underfunded…"

Aqua whitepaper 1.0, §3 — the gap the product lives in

The user journey — five steps, one sentence each

The 1inch mentor's ranking was explicit: UX first, user journey second, legitimate use case third, contracts last. So the journey is not documentation of the UI — it is the UI: a rail across the top advances as the user acts.

FEELS: recognition

Wallet — "this is me"

Big idle balances, and one attributed fact: 1inch's own July research — 85% of concentrated liquidity idle, $1.6B managed by hand. The user recognizes their own wallet in the statistic.

on-chain: nothing yet. Reading balances.
FEELS: safe leverage

Put to work — "nothing leaves"

Three presets (Careful / Balanced / Busy), each a single human decision: how many places one balance works at once. Copy insists: you are signing price rules, not a deposit.

on-chain: ship ×N through the canonical Aqua registry + budgets set on the skew provider.
FEELS: watching it work

Live market — water rises

Real fills drain real WETH. Water climbs the hulls, surcharge badges wake up on the drained side only — the user sees directional defense without reading a word.

on-chain: taker swaps through the official router; every fill a real ERC20 transfer.
FEELS: protected

Protected — the punch

A strategy crosses its load line. Storm vignette, then the green event strip: docked → re-shipped against what the wallet really holds. The invariant tile never leaves green.

on-chain: dock + ship signed automatically; budgets recomputed net of the other strategies.
FEELS: free to leave

Walk away — the receipt

One click docks everything. The close is a receipt, not a banner: markets served, fills settled, protections, and the number that defines the product — 0 deposits, 0 positions to unwind.

on-chain: dock ×N. The wallet was liquid the whole time.

The punch line we designed everything around

Wallet balance changed. Your quotes repaired themselves.

Every winning ETHGlobal demo we tore down has one remembered moment. Ours is autonomous: the Harbormaster acts on camera, unprompted, and the UI makes the causality legible in one strip — crossed the line → docked → re-shipped. Of the six prior "Build an Aqua App" submissions, only the one with a usable live UI won first place. None had autonomous protection. None had wallet signing. We have all three.

Process: two designers, one synthesis

v1 rebuilt the app around the journey. We then screenshotted the real screens and ran an independent vision critique (GPT-5.6) against our own review — two designers, no shared bias. Nine decisions accepted, one rejected:

  • ACCEPTEDMake the intervention unmissable — full-width event strip; it was the hero moment and it was invisible.
  • ACCEPTEDOne hero metric — Market coverage at display size; four equal tiles erased hierarchy.
  • ACCEPTEDLabel the metaphor — SAFE/TIGHT/DOCKING chips, "AUTO-DOCK LINE" caption. Never rely on maritime literacy.
  • ACCEPTEDProtocol prose out of the UI — one narrative line per screen; the whitepaper lives in the README.
  • ACCEPTEDEnd on a receipt — outcomes, not a banner. The journey pays off.
  • ACCEPTEDStorm vignette, solid surfaces, 8px type scale, journey rail rename (each ≤ 30 min of work).
  • REJECTED"Drop the $1.6B stat, it reads invented" — it is 1inch's own commissioned research. We attributed it inline instead of deleting it: in front of this sponsor it is a weapon, not a risk.

Real-world shape, tonight

  • Wallet mode shipped: any injected wallet becomes the maker and signs every ship/dock; empty accounts get one-click seeding on the fork. Demo signer stays default for reproducibility.
  • Vocabulary aligned with Aqua: Strategy (not berth) as the primary noun, SLAC — 1inch's own amplification metric — named on the hero tile, ship/dock as the verbs.
  • Open seam for the LP console (Henrik): everything is exported from web/src/lib/plimsoll.ts; a pro view mounts beside the journey without touching it.
