Doca

Read your positions from anywhere an agent can run

Doca ships a small MCP server: three read-only tools that let an AI agent check a maker's wallet, look up strategy state, and verify the one invariant that matters — can the wallet actually cover every promise it's made, at once.

What it exposes

ToolReturns
doca_walletMaker's WETH / USDC balanceread
doca_positionsPer-strategy WETH aboard, budget-remaining fraction, fee surchargeread
doca_healthCommitted WETH vs. wallet balance, honorable: true/falseread
ship / dock—not exposed

Why read-only

Shipping or docking a strategy needs a signature. Handing an agent a private key so it can move funds unattended is a custody decision this project isn't making by default — the person who holds the keys should decide when a promise gets made or revoked. Today an agent can watch a position and tell a human what to do about it. It cannot act on its own. See the roadmap below for what an authenticated write path looks like.

Run it

bun mcp/server.ts
# doca-mcp listening on :8420 -> POST /mcp

claude mcp add --transport http doca http://127.0.0.1:8420/mcp

One file, zero new dependencies: Bun.serve plus raw JSON-RPC eth_call against RPC_URL, reading addresses from the same web/src/deployment.json the app uses. No auth, no session state — every call is a fresh read.

Example call

curl localhost:8420/mcp -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
  "params":{"name":"doca_health","arguments":{"hashes":["0x8c9e..."]}}}'

{ "walletWeth": {"formatted":"2.0000"}, "committedWeth": {"formatted":"0.5000"},
  "headroomWeth": {"formatted":"1.5000"}, "honorable": true,
  "note": "honorable=true means the wallet actually holds enough WETH to cover
           every checked strategy's committed amount at once, even though
           nothing was ever deposited into Aqua." }

Roadmap

  • Authenticated write actions — ship/dock/fill behind an explicit, scoped authorization the wallet owner grants, not a standing key.
  • x402-metered premium data (concept only, not built) — deeper analytics (fee-curve history, cross-market skew comparisons, backtested budget presets) sold per-call over x402 instead of a subscription, once there's data worth metering.
